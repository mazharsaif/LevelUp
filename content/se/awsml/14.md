## 14. Boss: MLA-C02 final review

This is the final challenge. Book MLA-C02 when two timed mocks and the AWS Official Practice Exam all score 80% or better. If any is lower, spend another week on your weakest domain first.

### The exam

- In beta: 85 questions in 170 minutes for $75 (English only). At full release: 65 questions (50 scored) for $150.
- Multiple choice and multiple response only. Pass mark: 720 of 1,000. Beta results take about 5 business days.
- Weights: data preparation 28%; model and FM development 24%; deployment and orchestration 24%; operating, monitoring and securing 24%.
- Removed from C01, so you can skip them in old material: SageMaker Neo and edge optimisation, bring-your-own-container, model compression and pruning, EventBridge infrastructure monitoring, and loading training data from EFS or FSx.

### Keyword decoder

| The question says | Usually points to |
|---|---|
| "Least operational overhead" | A managed or serverless option (AI service, Bedrock, Firehose, serverless inference) |
| "Most cost-effective" | Spot, serverless, batch, a smaller model, Parquet, S3 Vectors, Savings Plans |
| "Near real time to S3" | Amazon Data Firehose |
| "Replay", "custom consumers" | Kinesis Data Streams |
| "Explain predictions", "bias" | SageMaker Clarify |
| "Drift" | Model Monitor (data, model quality, bias or attribution) |
| "Large payload", "long processing" | Asynchronous inference |
| "Many low-traffic models" | Multi-model endpoint |
| "Roll back automatically" | Deployment guardrails with CloudWatch alarms |
| "Fresh, private documents", "citations" | Bedrock Knowledge Bases (RAG) |
| "Harmful content", "PII in output", "ungrounded answers" | Bedrock Guardrails |
| "No internet access" | VPC with private subnets, VPC endpoints, network isolation |
| "Who did it" | CloudTrail; "is it configured correctly" → AWS Config |

### Mixed mock (15 questions)

1. 2 TB of CSV is queried daily on 3 of 120 columns. Cut cost most? (a) gzip (b) partitioned Parquet (c) EFS (d) a larger Athena workgroup
2. Fraud is 0.5% of rows. Which TWO help most? (a) accuracy (b) SMOTE (c) class weights (d) dropping the minority class (e) more epochs
3. A RAG system's answers are cut off mid-table. First fix? (a) a bigger LLM (b) structure-aware chunking with overlap (c) a higher temperature (d) fewer chunks
4. Churn decisions must be explainable to auditors. (a) a deep neural network (b) XGBoost with Clarify SHAP (c) k-means (d) a Bedrock FM
5. Validation loss rises after epoch 8 while training loss falls. (a) more epochs (b) early stopping or regularisation (c) a higher learning rate (d) remove the validation set
6. Compare a new model on live traffic without users seeing it. (a) A/B test (b) shadow variant (c) canary (d) blue/green all at once
7. A few requests an hour, unpredictable, lowest cost. (a) a real-time ml.m5.xlarge (b) serverless inference (c) provisioned throughput (d) EKS
8. Inputs are 1 GB and processing takes 8 minutes. (a) real-time (b) asynchronous (c) serverless (d) Lambda
9. Register a model only when AUC ≥ 0.8. (a) a Condition step (b) a CloudTrail rule (c) an email (d) a Config rule
10. Serve an open model fine-tuned outside AWS through Bedrock APIs. (a) Custom Model Import (b) JumpStart only (c) EC2 (d) Lambda
11. The knowledge base must pick up new S3 documents nightly. (a) EventBridge schedule → Lambda → `StartIngestionJob` (b) retrain the FM (c) a bigger embedding model (d) manual sync
12. Input distributions drift from training. (a) Model Monitor data quality (b) CloudTrail (c) Trusted Advisor (d) Inspector
13. Bedrock spend doubled with flat traffic. Check first? (a) the S3 storage class (b) tokens per request (c) VPC flow logs (d) the password policy
14. A RAG bot answers beyond its sources. (a) a word filter (b) a contextual grounding check (c) provisioned throughput (d) invocation logging
15. Scan ECR images for CVEs before deployment. (a) Macie (b) Comprehend (c) Inspector (d) Shield

**Answers.** 1b, 2 b+c, 3b, 4b, 5b, 6b, 7b, 8b, 9a, 10a, 11a, 12a, 13b, 14b, 15c.
