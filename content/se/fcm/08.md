## 8. Sign-in with Firebase Auth

This skill covers Firebase Authentication: what it gives you, how your own backend can trust it, and what it costs you in lock-in.

### What Auth gives you

Managed sign-in: email and password, phone (SMS), Google, Apple and other providers, and anonymous accounts. It also handles the chores you would otherwise write: password reset, email verification and session refresh. [consensus]

The client SDK signs the user in and holds the session. Users get a stable `uid`, which becomes the key for everything else (rules, documents, push tokens).

### The ID token

After sign-in the app receives an **ID token**: a short-lived signed JWT that proves who the user is. Your own backend can verify it with the Admin SDK, so a Firebase login can sit in front of an existing API.

```python
# pip install firebase-admin   (needs a service-account key / project)
import firebase_admin
from fastapi import Depends, FastAPI, Header, HTTPException
from firebase_admin import auth

firebase_admin.initialize_app()  # picks up credentials from the environment
app = FastAPI()

def current_uid(authorization: str = Header(...)) -> str:
    try:
        token = authorization.removeprefix("Bearer ")
        return auth.verify_id_token(token, check_revoked=True)["uid"]
    except Exception:
        raise HTTPException(status_code=401, detail="invalid token")

@app.get("/me")
def me(uid: str = Depends(current_uid)):
    return {"uid": uid}
```

`check_revoked=True` costs an extra lookup but catches tokens revoked after a password change or sign-out. The default is off. This verifies tokens from the client SDKs, not custom tokens you mint yourself.

### Limits and costs

- **Phone sign-in sends SMS**, which is billed and attractive to bots. Pair it with App Check and limits. [fast-moving]
- **Lock-in is high.** User records, provider links and password hashes (a Firebase-specific scrypt variant) live in Firebase. You can export users with the CLI (`firebase auth:export`), but you must handle the hashes or force a reset. [consensus; verify the current docs]
- **If you already have accounts**, adding Firebase Auth creates a second login system to keep in sync. LevelUp has its own accounts, so it does not need this.
