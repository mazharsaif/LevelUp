## 2. The Firebase map

This skill answers "what is Firebase, and what does it cost?" so you can pick one product without buying the whole catalogue.

### Firebase is a catalogue

Google bundles a dozen services under one console. They are separable: you can use Cloud Messaging and nothing else. Most of the confusion about "using Firebase" comes from forgetting this.

### The products at a glance

| Product | What it does | Reach for it when | Lock-in |
|---|---|---|---|
| Cloud Messaging (FCM) | Push from your server to an app install | You must wake a closed app | Low |
| Authentication | Managed sign-in (social, phone, email) | You have no accounts system | High |
| Firestore / Realtime Database | Managed database with live listeners | You want a backend with no server | High |
| Cloud Functions | Serverless code | You want endpoints without running a server | Medium |
| Hosting | Static site and CDN hosting | You have a web front end | Low |
| Crashlytics / Analytics | Crash reports and usage data | You have a published app | Medium |
| Remote Config / App Check | Feature flags and abuse protection | You change behaviour without a release | Medium |

The lock-in column is a judgment [depends], not a measurement.

### What it costs

- **FCM itself is free**, with no per-message charge, and works on the no-cost **Spark** plan [consensus, fast-moving: check Firebase's pricing page].
- Other products, such as databases, functions, storage and SMS-based phone sign-in, are where bills appear. Some need the pay-as-you-go **Blaze** plan, which requires a card.
- If your server sends the pushes and you use none of those products, you pay nothing.
- Publishing on the Play Store has its own one-time fee, but sideloading an APK does not need it, and FCM does not require it.

### Roots versus leaf

- **Push is a leaf.** Swapping FCM later means changing the sender and the client registration. Nothing else depends on it.
- **Database and login are roots.** Firestore and Firebase Authentication *are* your data and identity layer. Migrating them is a real project [consensus].
- The rule of thumb: adopt the leaf, and think hard before adopting the roots.
