## 2. The Firebase map

This skill answers "what is in Firebase, and what does it cost?" so you can pick one product without buying the whole catalogue.

### Project, apps and the config file

A Firebase **project** is a Google Cloud project with Firebase turned on. You register one or more **apps** (Android, iOS, web) in it, and you get a config file (`google-services.json` for Android) that identifies your app to Google.

That file is **not a secret**. It names your project but does not grant access. Rules and App Check are what protect you. A **service-account key**, on the other hand, gives admin power and must never be committed to git.

### Products at a glance

| Product | What it does | Reach for it when | Lock-in |
|---|---|---|---|
| Authentication | Managed sign-in and ID tokens | You have no accounts system | High |
| Firestore | Document database with live listeners and offline cache | App-driven, document-shaped data | High |
| Cloud Storage | User-uploaded files | You store images, audio or PDFs | Medium |
| Cloud Functions | Serverless code on triggers | You need trusted server logic without a server | Medium |
| Hosting | Static hosting on a CDN | You have a web front end | Low |
| Cloud Messaging (FCM) | Push from your server to an app install | You must wake a closed app | Low |
| Crashlytics, Analytics, Remote Config, App Check | Crash reports, usage data, flags, abuse protection | You have a published app | Low to medium |
| Newer: Data Connect, App Hosting, AI Logic | Postgres behind a typed API, server-rendered hosting, generative AI from clients | Specific needs | Varies [fast-moving] |

The lock-in column is a judgment [depends], not a measurement.

### Plans and what they cost

- **Spark** is the no-cost plan with free usage quotas. **Blaze** is pay as you go and links a billing account.
- **Cloud Functions requires Blaze.** Analytics, Crashlytics, App Check, Cloud Messaging, A/B Testing and Performance Monitoring are free on both plans. [checked 2026-11-23, fast-moving]
- Firestore's standard free quota allowed 50,000 reads, 20,000 writes and 20,000 deletes per day. [checked 2026-11-23, fast-moving]
- Blaze has budget **alerts**, not a hard cap by default.

### Roots versus leaf

- **Push and hosting are leaves.** Swapping them touches only the sender or the deploy step.
- **Firestore and Authentication are roots.** They become your data and identity in Google's terms. Migrating them is a real project. [consensus]
- Rule of thumb: adopt the leaves freely, and think hard before adopting the roots.

### Firebase sits on Google Cloud

A Firebase project *is* a Google Cloud project, so the same billing, IAM roles, service accounts and logs apply. You can mix in Cloud Run or BigQuery when you outgrow the wrappers. That is the escape hatch, and it is also why permissions and bills can feel more complex than "an app SDK" suggests.
