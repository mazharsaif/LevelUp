## About this course

Firebase is a set of ready-made backend services from Google: sign-in, a database, file storage, code that runs in the cloud, web hosting, push notifications and app monitoring. Instead of building and running a server yourself, your app talks to these services directly.

In this course you build one small project from start to finish: a **Notes app**. People sign in, write notes, attach a photo and get a reminder as a push notification. Every skill adds one piece, so you always see why a feature exists before you use it.

### What you will be able to do

- Explain what Firebase is, and decide when it is the right tool and when it is not.
- Set up a project on your own computer and test everything for free with the emulators.
- Add sign-in, store and query data, and protect it with security rules.
- Run code in the cloud, host a web app and store photos.
- Send push notifications that reach a phone even when your app is closed.
- Understand the costs, avoid surprise bills and launch safely.

### What you need

- Basic reading knowledge of JavaScript. A little Python helps in a few examples.
- Node.js installed on a computer, and a code editor.
- A Google account, only to create a Firebase project. The hands-on labs run on your own computer and cost nothing.

### How each skill works

Each skill takes about 10 to 15 minutes and is split into short parts you can read separately. You will find a worked example, a hands-on **Try it**, a list of common mistakes and a short **Check yourself**. When you finish all the parts, practice questions open so you can test what you learned.

### Things change

Firebase changes often. Prices, limits and button names move. Where it matters, a skill tells you to check the official Firebase documentation instead of trusting a number that may be old.
