# Present tense: irregular verbs and -ir / -re verbs
intro: A handful of very common verbs don't follow the -er pattern: aller, faire, venir, prendre, vouloir, pouvoir, devoir, savoir. You need them in almost every sentence, so learn them like être and avoir. Then two small regular groups: -ir verbs like finir and -re verbs like attendre.
---
### aller, faire, venir, prendre
| | aller (go) | faire (do, make) | venir (come) | prendre (take) |
|---|---|---|---|---|
| je | vais | fais | viens | prends |
| tu | vas | fais | viens | prends |
| il / elle / on | va | fait | vient | prend |
| nous | allons | faisons | venons | prenons |
| vous | allez | faites | venez | prenez |
| ils / elles | vont | font | viennent | prennent |
Like prendre: **apprendre** (learn), **comprendre** (understand). Like venir: **revenir** (come back).
### vouloir, pouvoir, devoir, savoir
| | vouloir (want) | pouvoir (can) | devoir (must) | savoir (know) |
|---|---|---|---|---|
| je | veux | peux | dois | sais |
| tu | veux | peux | dois | sais |
| il / elle / on | veut | peut | doit | sait |
| nous | voulons | pouvons | devons | savons |
| vous | voulez | pouvez | devez | savez |
| ils / elles | veulent | peuvent | doivent | savent |
These four are followed by an **infinitive**: Je veux **partir**. Tu peux **répéter** ? Je dois **travailler**. Je sais **nager**.
### -ir verbs like finir
Remove -ir, add: -is, -is, -it, -issons, -issez, -issent. je fin**is**, nous fin**issons**, ils fin**issent**. Also: choisir, remplir, réussir.
Some -ir verbs are shorter: partir → je pars, nous partons; sortir → je sors; dormir → je dors.
### -re verbs like attendre
Remove -re, add: -s, -s, — (nothing), -ons, -ez, -ent. j'attend**s**, il attend, nous attend**ons**. Also: répondre, vendre, descendre, entendre, perdre.
### Other useful irregulars
- **dire:** je dis, vous **dites**, ils disent. **lire:** je lis, nous lisons. **écrire:** j'écris, nous écrivons.
- **boire:** je bois, nous buvons, ils boivent. **mettre:** je mets, nous mettons. **voir:** je vois, nous voyons. **connaître:** je connais, il connaît.
---examples
- Je vais au marché le samedi. | I go to the market on Saturdays.
- Qu'est-ce que tu fais ce soir ? | What are you doing tonight?
- Vous pouvez répéter, s'il vous plaît ? | Can you repeat, please?
- Je dois partir à huit heures. | I have to leave at eight.
- Nous prenons le train de dix heures. | We're taking the ten o'clock train.
- Le cours finit à midi. | The class finishes at noon.
---mistakes
- vous faisez | vous faites | faire: vous faites (like vous êtes, vous dites).
- ils allent | ils vont | aller is irregular: ils vont.
- Je peux de parler. | Je peux parler. | pouvoir / vouloir / devoir + infinitive, no "de".
- Je sais Paris. | Je connais Paris. | savoir = facts, skills; connaître = people, places.
---questions
- Je ___ (aller) à la gare. :: vais
  opts: vais; vas; va; allons
- Vous ___ (faire) du sport ? :: faites
  opts: faites; faisez; fais; font
- Ils ___ (aller) au cinéma. :: vont
  opts: vont; allent; vas; allez
- Tu ___ (venir) avec nous ? :: viens
  opts: viens; venez; vient; venons
- Nous ___ (prendre) le bus. :: prenons
  opts: prenons; prenez; prennent; prends
- Je ___ (vouloir) un café. :: veux
  opts: veux; veut; voulez; voulons
- ___-vous m'aider ? (pouvoir) :: Pouvez
  opts: Pouvez; Pouvons; Peux; Peuvent
- Tu ___ (savoir) nager ? :: sais
  opts: sais; connais; sait; savez
- Elle ___ (finir) à cinq heures. :: finit
  opts: finit; finis; finissent; fini
- J'___ (attendre) le bus. :: attends
  opts: attends; attend; attendons; attendez
- Write the form: ils + faire → ils ___ :: font
- Write the form: ils + prendre → ils ___ :: prennent
