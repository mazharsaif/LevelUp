# Nouns: masculine or feminine, singular or plural; professions
intro: Every French noun is either masculine or feminine – even things: le livre (the book) is masculine, la table (the table) is feminine. There is no neuter. Learn each noun together with its article, the way the word list shows it. Plurals are easy to write (usually + s) and the s is silent.
---
### Gender: some helpful endings
| Usually masculine | Examples | Usually feminine | Examples |
|---|---|---|---|
| -age | le fromage, le voyage | -tion, -sion | la question, la télévision |
| -ment | l'appartement | -té | la santé, l'université |
| -eau | le bureau, le gâteau | -ette | la baguette, la fourchette |
| -isme | le tourisme | -ure | la voiture, la confiture |
| -er, -ier | le cahier, le papier | -ence, -ance | la France, la naissance |
> warn: There are exceptions: **la** plage, **la** page, **l'**eau (f.), **le** musée. Always learn the article with the noun.
### Plural
- Usually add **s**: un livre → des livre**s**. The s is not said: the article tells you it's plural (le → **les**, un → **des**).
- Already ending in -s, -x, -z: no change: le bras → les bras, le prix → les prix.
- -eau, -au, -eu → add **x**: le gâteau → les gâteau**x**, le jeu → les jeu**x**.
- -al → **-aux**: le journal → les journ**aux**, l'animal → les anim**aux**.
- Special: l'œil → les **yeux**.
### People and professions: masculine and feminine
| Pattern | Masculine | Feminine |
|---|---|---|
| + e | un étudiant, un ami | une étudiant**e**, une ami**e** |
| -ien → -ienne | un informaticien | une informatic**ienne** |
| -er → -ère | un boulanger | une boulang**ère** |
| -eur → -euse | un vendeur, un serveur | une vend**euse**, une serv**euse** |
| -teur → -trice | un acteur, un directeur | une ac**trice**, une direc**trice** |
| same word | un journaliste, un élève | une journaliste, une élève |
| same word (only the article changes) | un médecin, un professeur | une médecin, une professeur(e) |
### No article after être with a profession
**Je suis professeur.** Elle est infirmière. Il est ingénieur. (But with an adjective or with c'est you need un / une: C'est **un** bon médecin.)
---examples
- Le livre est sur la table. | The book is on the table.
- J'ai deux gâteaux et trois journaux. | I have two cakes and three newspapers.
- Mon frère est serveur et ma sœur est serveuse. | My brother is a waiter and my sister is a waitress.
- Elle est médecin à l'hôpital. | She is a doctor at the hospital.
- C'est un bon professeur. | He's a good teacher.
---mistakes
- Je suis un étudiant. | Je suis étudiant. | No un / une with a job or status after être.
- les journals | les journaux | -al → -aux.
- Saying the plural s: "lay leevrs" | lay LEEVR | The plural s is silent.
- un actrice | une actrice | Feminine nouns take une / la.
---questions
- Masculine or feminine? télévision :: feminine
  opts: feminine; masculine
  note: -sion / -tion → feminine: la télévision.
- Masculine or feminine? fromage :: masculine
  opts: masculine; feminine
  note: -age → masculine: le fromage (but la page, la plage!).
- Plural of le gâteau → les ___ :: gâteaux
  opts: gâteaux; gâteaus; gâteau; gâteauxs
- Plural of le journal → les ___ :: journaux
  opts: journaux; journals; journal; journeaux
- Plural of le prix → les ___ :: prix
  opts: prix; prixs; prix-s; prixes
- Feminine of un vendeur → une ___ :: vendeuse
  opts: vendeuse; vendeure; vendrice; vendeur
- Feminine of un acteur → une ___ :: actrice
  opts: actrice; acteuse; acteure; acteur
- She is a doctor. :: Elle est médecin.
  opts: Elle est médecin.; Elle est une médecin.; Elle a médecin.; Elle est la médecin.
- Feminine of un étudiant → une ___ :: étudiante
- Feminine of un informaticien → une ___ :: informaticienne
