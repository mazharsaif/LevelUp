# This and that: ce, cet, cette, ces
intro: The demonstrative adjective points at something: this book, that dress, these shoes. French has one set of words for both "this" and "that" – it agrees with the noun like an article.
---
| | singular | plural |
|---|---|---|
| masculine | **ce** livre | **ces** livres |
| masculine before a vowel / h | **cet** hôtel, **cet** ami | **ces** hôtels |
| feminine | **cette** robe | **ces** robes |
> tip: **cet** and **cette** sound the same (SET). **ces** sounds like "say", with liaison before a vowel: ces‿enfants (say-zahñ-FAHÑ).
### Time expressions
ce matin (this morning), cet après-midi, **ce soir** (tonight), cette semaine, ce week-end, **cette année**, cet été.
### this one / that one: -ci, -là
To compare two things in a shop: Je préfère **cette robe-ci** (this one here) ou **cette robe-là** (that one there). On its own: **celui-ci / celle-ci** (this one) – to recognise at A1.
### ça and cela
**ça** = "that / it" for a thing you don't name: Je prends **ça**. **Ça** coûte combien ? (cela is the written form.)
---examples
- Ce pull est trop petit. | This jumper is too small.
- Cet hôtel est très calme. | This hotel is very quiet.
- Cette robe coûte cinquante euros. | This dress costs fifty euros.
- Ces chaussures sont confortables. | These shoes are comfortable.
- Qu'est-ce que tu fais ce soir ? | What are you doing tonight?
- Je prends ça, s'il vous plaît. | I'll take that, please.
---mistakes
- ce hôtel | cet hôtel | cet before a vowel or silent h.
- cette livre | ce livre | livre (book) is masculine.
- ces robe | ces robes | ces + plural noun.
- cette soir | ce soir | soir is masculine.
---questions
- ___ livre est intéressant. :: Ce
  opts: Ce; Cet; Cette; Ces
- ___ hôtel est cher. :: Cet
  opts: Cet; Ce; Cette; Ces
- ___ chemise est trop grande. :: Cette
  opts: Cette; Ce; Cet; Ces
- ___ fleurs sont belles. :: Ces
  opts: Ces; Cette; Ce; Cet
- Je travaille ___ après-midi. :: cet
  opts: cet; ce; cette; ces
- On se voit ___ semaine ? :: cette
  opts: cette; ce; cet; ces
- ___ week-end, je vais à la mer. :: Ce
  opts: Ce; Cet; Cette; Ces
- Je prends ___, s'il vous plaît. (that, pointing) :: ça
  opts: ça; ce; cette; cet
- Write "this evening" (tonight): ___ soir :: ce
- Write "these children": ___ enfants :: ces
