Gate board: emblem below "Enter", bigger gate-type emblems

Design review for feedback 20261124-053734-batul-82bb (Batul, Hunter's Path, gate board): "move the gate type emoji from right next to the gate title to below the Enter gate button, and create bigger emblems for each gate type." Nothing under app/ has been changed. Everything on this page is inline CSS/SVG, drawn from scratch.

What "gate type" means in the code. The board is built from 13 gate templates (app/data/life.json), each with its own emoji. Each also has a stat (Body, Mind, Discipline, Health), a kind (daily, target, abstain, milestone) and a length which sets the rank E to S. There is also a "Create your own gate" card (sparkle). I made one emblem per template (13) plus one for custom gates (14). Emblem colour follows the stat; the rank stays in the existing rank badge (and as a ring or ribbon colour in some styles).
Themes. The app has no theme named "Playful" or "Plain". I mapped them to Classic (green, chunky, light = "Playful"), Calm (soft, serif headings = "Plain") and Hunter System (neon blue). Hunter Mid and Hunter Simple use the same cards with less glow, so Hunter covers them.

1. Current gate card (reference)

Emoji sits left of the title, Enter button on the right. Emoji is about 30px.

2. Layout options (emblem below the Enter button)

Each option is shown in Classic (Playful), Calm (Plain) and Hunter at 390px wide, all using emblem style C or B as noted. Cards shown: a D, a B and a C gate so rank and stat colours vary.

Option A: Right rail (smallest change)

Same card, same text. The right column becomes Enter button on top, a 64px emblem right under it. Title now gets the full left width, no emoji beside it.

Pros
Closest to what Batul asked for, smallest code change, cards stay short (about 120px), many gates visible per screen.
Cons
Emblem is only about 64px, so "bigger" is modest. Right column is narrow so the Enter button must stay small. Open/Ran states ("Open ✓", "Cleared ✓ + Enter again") need to fit above the emblem.

Option B: Portal card (big centred emblem)

Centred layout: title and rank, blurb, meta line, a wide Enter button, and a large 96px emblem sitting below like a gate portal.

Pros
The emblem is large and is the hero of the card, most "emblem" feel, easy to tap Enter (wide button), good for the Hunter look.
Cons
Cards are about 3x taller (about 300px), so the board of 13 gates needs a lot more scrolling. The emblem below the button is a little unusual (reads after the action).

Option C: Two-column tiles

The board becomes a 2-column grid of tiles: title, rank, a full-width Enter button, then an 84px emblem under it. The blurb moves to the gate's own page (or a tap-to-expand).

Pros
Big emblems and a compact board (13 gates in about 7 rows), reads like a collection of gates, and the emblems get a clear place.
Cons
Blurb and "Mind · 28 days" line need shortening or hiding; long titles wrap to 3 lines on 390px phones; bigger rewrite of the card and its tests; open/ran states need a new spot.

Recommendation

Go with Option A with a larger emblem (72px, emblem style B "Crest" in Classic and Calm, style C "Hunter" in Hunter themes). It does exactly what was asked with the least change and keeps the board scannable. If you want a stronger statement, Option C is the best bigger step; Option B is the most striking but the board becomes very long. Style recommendation is in section 3.

3. Emblem set (14 types, 3 styles, big and small)

Colour = stat. The same glyph is used in all three styles, so Mazhar can pick the style separately from the layout. Big = 72px, small = 32px (for places like "Your record" and Today, which currently use the emoji).

Style A: Flat badge (round, filled, rank ring)

Style B: Shield crest (rank ribbon at the foot)

Style C: Hunter glow (hex, neon line art, on dark)

Style recommendation. Crest (B) for Classic and Calm: it shows the rank without extra text and looks like a "gate seal". Hunter glow (C) in Hunter themes. Flat badge (A) is the fallback if you want one style for all themes (it works everywhere, but carries least rank information). Implementation would be one SVG sprite file and a theme-based choice, no extra downloads in practice. The emoji would stay as the fallback for a custom gate icon.
