## Key mechanics (one line each)
- **Study helper (chatbot, 11-23)**: "ask about this card", free, daily cap (10/day/learner) currently OFF (`LIMIT_ON` in ask.py). Server `server_fastapi/ask.py` + routes in main.py (`GET /api/ask/quota`, `POST /api/ask`, `POST /api/ask/feedback`): GroqCloud `openai/gpt-oss-120b`, `reasoning_effort: low`, `max_completion_tokens` 450 (one retry with double if the answer comes back empty/cut), single turn + the previous Q&A, ~4 sentences. **Key**: env `GROQ_API_KEY` or a one-line file `~/levelup-data/ask/groq.key` (chmod 600, outside git; no restart needed). Off (no chips shown) until a key exists. Other env: `ASK_DAILY_CAP`, `ASK_MAX_TOKENS`, `ASK_MODEL`, `ASK_PAUSED=1` (kill switch). Rules: before you answer only a 💡 hint (the correct answer never goes in the prompt; a hint that contains it is replaced by a canned one); 1 request/2 s and 30/h per learner; links/code refused; answers cached per item+question (🚩 evicts), cached and failed calls are free; every call logged to `~/levelup-data/ask/YYYY-MM.jsonl` (review the 🚩 ones); nothing that identifies the learner goes to Groq. Client `app/js/ask.js` (sheet, chips, states) + hooks in lesson.js (`askContext`, before/after rows) and app.js (reader "Explain simply", Settings note). Reader cards use their own prompt (`step_type: reader_card`). Design + mockups: `docs/design/chatbot/`. Not built: Save as note, Ask & Notes screen, streaming.
- **Translator endpoint (11-24)**: `POST /api/translate` `{lang: de|fr, dir: to_en|from_en, text}` (text clipped to 200 chars, never 422) -> `ask.translate()`: same Groq key, per-learner rate limit (1 per 2 s, 30 per hour, shared with the helper), `LIMIT_ON` daily cap, cache (`tr` keys in `ask/cache.json`) and log (`mode: translate` in `ask/YYYY-MM.jsonl`), but its own translate-only prompt in JSON mode (`translation`, `casual`, `article`, `plural`, `words[{w,g,n}]`; output validated and cleaned). Sends only the typed text and direction, nothing from lessons. 🚩/👍 reuse `POST /api/ask/feedback` (🚩 evicts the cached answer). No new env or config: it is on whenever the study helper is. UI in `app/js/translate.js` (mounted by `wordsView`); `app/js/ask.js` is reused for "Ask the helper about this".
- **Say it in German** (phrases): English situation → whole German phrase. New phrase = word bubbles (+2–3 distractors); once produced correctly (`S.say[de]` count) = mix of bubbles/typing (typing 45→65 %). Replaces the final-round MC in phrase bits, plus 2 spaced phrases from earlier parts. `sayItems()` skips phrases with …, (), mid-sentence a / b (129 of 167 usable).
- **Pass mark**: a lesson part counts only at ≥60% first-try accuracy (`PASS_ACC` in lesson.js); otherwise "Almost there!" + Try again, small XP, no completion/level/learnWord. Long new phrases get `guidedSayStep` (2–3 key words blank) before full Say-it. Lesson steps ignore taps for 0.45 s (`.arming`) to stop double-tap skips.
- Lessons are split into **bits** (vocab: 4 words, phrases: ~5); interleaved teach→test; sentence "Complete the sentence" (only known words are blanks) plus gap-fill.
- MC options are filtered so no distractor shares a meaning (`overlaps()`, synonyms); typing accepts same-meaning words.
- **A1 %** = vocab 55 (by words × memory health) + grammar 30 + phrases 15. Coverage (lessons done) drives pace and weeks.
- **Level** 1→100 = A1 % (level 100 = A1 reached); after that +1 level per 200 XP (`a1XP` marks the XP when A1 was reached). Rank E/D/C/B/A/S at 0/10/25/45/70/95 %.
- **Reviews**: active recall, Again/Hard/Good/Easy, SM-2. Overdue words fade (−1/14 per day, floor 25 %); "Again" counts half → level can drop (level-down sheet).
- **XP**: lesson bit 4+correct (max 16), +10 per finished lesson; review +0.2 Good/Easy, −0.5 Again, +1 at ≥80 % recalled, rounded once per session (can be −1); missed review day −10…−30 (`pen`).
- **Daily goal**: auto by default = remaining lesson XP ÷ days to target + review allowance (20–300, set once per day); manual option.
- **Weeks**: Monday-start, from the user's start date to target date; each lesson goes into the week where the linear pace reaches it.
- **Diamonds**: +5 for a cleared daily quest; streak gift boxes at 7/14/21/30/45/60/75/90/120/150/180/365 days.
- **Rank emblem** (11-20, replaced the Hunter/Huntress character, hero picker and Settings hero option): `rankEmblem(lv, size, r)` in hero.js = the rank letter E→S with a purple halo that grows with the level (`--a` = aura 0→1); top bar, Status card, level-up screen ("✦ Rank up ✦"). Titles are "E-Rank" … "S-Rank". `settings.hero` and app/avatars are unused leftovers. **Ranks page** `#/ranks` (`ranksView`, `RANK_INFO` in app.js): opened by tapping the emblem (top bar, Status card with an ⓘ) or "All ranks ›"; S at the top down to E, each with name (Newcomer/Explorer/Speaker/Traveller/Local/A1 Master), % of A1, level, aura, a can-do line (same for every language course, `{lang}` from the course title) and when you'll get there (recent pace, else the start→target plan).
